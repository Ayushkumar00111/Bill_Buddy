# Bill Buddy 💰

A Full Stack Subscription Management App

## 🚀 Features
- User Authentication (JWT)
- Add / Edit / Delete Subscriptions
- Profile Page
- Protected Routes
- MongoDB Database
- Fully Deployed (Frontend + Backend)

## 🛠 Tech Stack
Frontend:
- React (Vite)
- Axios
- Tailwind / CSS

Backend:
- Node.js
- Express.js
- MongoDB
- JWT Authentication
- Bcrypt

## 🌐 Live Demo
Frontend: https://bill-buddy-woad.vercel.app
Backend: https://your-backend.onrender.com

## ⚙️ Setup Locally

### Backend
cd backend
npm install
npm run dev

### Frontend
cd frontend
npm install
npm run dev
