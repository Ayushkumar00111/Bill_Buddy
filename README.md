# Bill Buddy 💰

A Full Stack Subscription Management App

## 🚀 Features
- User Authentication (JWT)
- Add / Edit / Delete Subscriptions
- Profile Page
- Protected Routes
- MongoDB Database
- Fully Deployed (Frontend + Backend)

## 🛠 Tech Stack
Frontend:
- React (Vite)
- Axios
- Tailwind / CSS

Backend:
- Node.js
- Express.js
- MongoDB
- JWT Authentication
- Bcrypt
