# BillBuddy – Subscription Management Platform

BillBuddy is a MERN stack web application that helps users track, manage, and analyze their digital subscriptions.  
It provides real-time insights into active, expired, and unused subscriptions along with wasted money analytics.

---

## 🚀 Features

- User Authentication (JWT-based)
- Secure Login & Registration
- Add and manage subscriptions
- Automatic subscription status detection
  - Active
  - Expired
  - Unused
- Analytics dashboard
  - Total spend
  - Wasted money
  - Subscription counts
- Protected APIs
- Dark-themed modern UI

---

## 🛠 Tech Stack

**Frontend**
- React (Vite)
- Axios
- React Router
- CSS (Dark UI)

**Backend**
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication
